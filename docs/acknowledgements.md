# Acknowledgements

## WordSwarm

The physics-based animation engine at the core of AnimatedWordCloud was created by **Michael Kane** in the [WordSwarm](https://github.com/thisIsMikeKane/WordSwarm) project.

WordSwarm pioneered the concept of animating word frequencies using a Box2D physics simulation, where words float, collide, and resize in real time as their relative frequencies change across time periods. AnimatedWordCloud builds on this foundation by wrapping it into a pip-installable Python package with support for time-series text data, n-gram extraction, automatic pre-processing, and MP4 video export.

We are grateful to Michael Kane for making WordSwarm open source.
